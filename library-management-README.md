A single-page web application built to demonstrate core **Data Structures** concepts through a real-world Library Management system. Built as part of my 2nd semester B.E. CSE Data Structures coursework.

---

## ✨ What it does

- **Catalogue books** — add, search, and manage book records
- **Member management** — register and track library members
- **Book transactions** — borrow and return books with tracking
- **Data structure visualizer** — see how arrays, linked lists, stacks and queues work visually
- **Search** — linear search with step-by-step visualization
- **Fine management** — calculate and track overdue fines

---

## 🧠 Data Structures Used

| Structure | Used For |
|---|---|
| **Array** | Storing and accessing book catalogue |
| **Linked List** | Managing member records dynamically |
| **Stack** | Tracking return history (Last In First Out) |
| **Queue** | Managing borrow requests (First In First Out) |

---

## 📋 Modules

1. **Cataloguing** — Add and manage books with title, author, ISBN
2. **Transactions** — Borrow and return books
3. **Search** — Linear search with visual step-by-step animation
4. **Member Management** — Register and manage library members
5. **Fine Management** — Calculate overdue fines automatically
6. **DS Visualizer** — Interactive visualization of data structures

---

## 🛠️ Built With

- **HTML5** — structure and semantic markup
- **CSS3** — styling and responsive layout
- **JavaScript** — data structure logic, DOM manipulation, search visualizer

---

## 🚀 How to Run

No installation needed — it's a single HTML file.

1. Download `library_management_v2.html`
2. Open it in any browser (Chrome, Edge, Firefox)
3. All features work instantly — no server needed
